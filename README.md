# nvim-config

[LazyVim](https://www.lazyvim.org) based Neovim config (nordic theme).

## Install

macOS / Linux:

```sh
curl -fsSL https://raw.githubusercontent.com/__USER__/nvim-config/main/install.sh | sh
```

Windows (PowerShell):

```powershell
irm https://raw.githubusercontent.com/__USER__/nvim-config/main/install.ps1 | iex
```

An existing config is backed up to `nvim.bak.<date>`. Plugins install on first `nvim` launch.

## Keys

| Key | Action |
| --- | --- |
| `<leader>tt` | Toggle terminal on the right (25% width) |
| `Esc Esc` | Terminal mode -> normal mode |
| `Ctrl-h` / `Ctrl-l` | Move to left / right window |
| `Shift-h` / `Shift-l` | Previous / next buffer |
